## 当前实现

- 把现有 `CI` 的 push branch filter 扩为 `main`、`master` 与 `codex/**`；PR workflow、PostgreSQL 17 测试服务、Compose smoke 与权限不变。
- 固定到 GitHub Actions 官方 Node 24 版本的 immutable commit SHA，并固定 `ubuntu-24.04`，消除 v4 action 的 Node 20 runtime deprecation 和 `ubuntu-latest` 即将自动迁移的警告。
- README 指向当前交接，V1.3 交接及原始失败/通过证据保留。
- 推送分支后，从 `gh run list --branch codex/v1.4-postgresql-acceptance` 找到本次 workflow run，再检查 quality 和 docker-smoke jobs。quality job 用仓库已有 `TEST_DATABASE_URL` 执行全部 API/database suites 和全量 `npm run check`；Compose job 使用其独立 GitHub runner。
