# V1.3 AI Provider configuration and acceptance boundary

The default stays `AI_PROVIDER=mock`, `ENGLISH_AI_MODE=demo`, `AI_ALLOW_PAID_CALLS=false`. No keys are required for local use. This version implements the transport adapter but has **not** run or accepted any paid model, live account credentials, real-model quality or billing. All Provider regression transports are simulated.

Supported server providers: `mock`, `deepseek` (existing model/key names), and `openai-compatible` (Chat Completions endpoint). The compatible adapter appends `/chat/completions` to `AI_BASE_URL`; the chosen model must support system/user messages, JSON object mode, `max_tokens`, and the documented completion envelope. This is a compatibility contract, not a claim that every model or proxy supports it. HTTPS is required except loopback HTTP; embedded URL credentials/query/hash are rejected. Keys stay server-side, outside Git and browser DTOs.

The project does not auto-create, discover or reuse credentials. A future user-authorized configuration can select `AI_PROVIDER=openai-compatible`, an explicit `AI_MODEL`, `AI_BASE_URL`, server-only `AI_API_KEY`, and explicitly set `AI_ALLOW_PAID_CALLS=true`. Merely choosing a provider or having a key never enables network requests. Existing DeepSeek configuration also goes through this gate. Keep the gate false for local acceptance.

These are process environment variables. `npm run dev` does not automatically load a root `.env`. Set authorized configuration in the launching shell, or explicitly use `node --env-file=.env apps/api/dist/server.js` after building; keep secrets out of shell command arguments, terminal output and committed files. This task never reads a key file or opts into that startup command.

- `AI_TIMEOUT_MS`: 1,000–120,000 ms per attempt; default 15,000.
- `AI_MAX_ATTEMPTS`: 1–3 total attempts; default 3. Retry network failure, timeout, 429 and 5xx, with bounded 250/500 ms delays. Do not retry authentication, cancellation, other 4xx or malformed/truncated/schema-invalid output.
- `AI_FALLBACK=mock|none`: default mock. Eligible transient/invalid-output failures can return existing offline content, visibly labeled `mock` (English `demo`). Authentication, disabled calls, cancellation and usage-storage failure stay explicit errors. English offline fallback retains its three supported original demo topics; an unsupported topic returns `REAL_AI_REQUIRED`, not invented model output.
- `ENGLISH_AI_MODE=demo|real`: independent, preserves the existing English workflow. `real` selects the configured compatible provider or legacy DeepSeek, with the same explicit paid gate, retry/timeout and ledger.

The shared client honors a supplied AbortSignal. Studio and English HTTP routes forward disconnect cancellation; Growth analyze/generate/batch currently finish within the configured server attempt budget even if the browser disconnects. Web requests time out after 30 seconds, potentially before a slow configured real provider finishes. A timeout does not prove the write failed: check saved history before retrying. The batch lock/revision checks protect one API process; this version has no background queue or cross-process generation lock. Keep one writing API instance per local database.

Explicit English `openai-compatible` uses only `AI_API_KEY`/`AI_MODEL`; explicit `deepseek` uses only `DEEPSEEK_API_KEY`/`DEEPSEEK_MODEL`. They never borrow credentials from each other. The original `AI_API_KEY`/`AI_MODEL` DeepSeek alias is retained only for legacy English `real` with no non-Mock provider selection. No key crosses to a different explicitly selected endpoint.

The server writes `AI_USAGE_PATH` (default `data/ai-usage.jsonl`) after every non-Mock call/blocked attempt. Records survive API restart and contain provider, model, outcome, total attempts, duration, available input/output token counts, error code and cost estimate. They contain no prompts, raw output, keys or base URL. Read the newest 1,000 entries through `GET /api/v1/ai/usage`. A missing ledger returns an empty list; corrupt/unwritable storage returns the normal request-id error envelope. Recording failure blocks a successful result or silent fallback.

Set **your own current prices**, in `AI_COST_CURRENCY` (default USD), through `AI_INPUT_PRICE_PER_MILLION` and `AI_OUTPUT_PRICE_PER_MILLION`. Estimate = `(inputTokens × inputRate + outputTokens × outputRate) / 1,000,000`. Missing usage or rates stays `null`, never zero. The ledger is not a billing invoice and cannot measure tokens charged by an upstream that times out or omits usage. Unknown retries therefore cannot imply an exact total charge. Back up this ignored ledger alongside SQLite and English artifacts.

Reference: [official Chat Completions request/response](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create). Legacy DeepSeek class remains available for existing isolated contract tests; all application configuration factories use the common gated client. The offline ingestion analyzer intentionally remains rules-based.
