## 2026-10-05：复盘生成后无法直接复制发布，审核页面拥挤

### ISSUE

AI OUTPUT QUALITY / BUG / UX FRICTION：用户实测长 Markdown 复盘被直接带入稿件，包含聊天开场、表格、加粗与引用符号；审核区域窄列和拒绝控件逐字换行，不能方便核对并复制发布。

### ROOT CAUSE

离线生成直接拼接整段 `whatHappened`；旧纯文本转换的表格分支提前返回，未清理单元格格式。复制按钮只提供独立字段。审核根节点复用了全局 `.review-workspace` 网格类，导致标题和编辑区落入不适用的列。

### CHANGE

- API 离线生成从复盘抽取一个经历、提醒和下一次行动，形成短段落；保留原复盘与 debug evidence。真实模型提示明确完整正文格式，但没有调用真实模型。
- contracts 提供纯文本转换与发布字段组合：正文、未重复的结尾问题和标签；标题单独复制。保留数字、链接及实际文字。
- 审核顶部增加可选中、可复制的发布文案，跟随尚未保存的编辑；剪贴板失败可手动复制。旧稿只转换复制视图，不自动覆盖正文或缩写历史稿件。
- 审核根类独立命名，局部修复宽度、字号、窄屏布局和拒绝控件；人工保存、审核及发布状态约束保留。
- 原复盘直接生成入口、V1.1 加固、English、PNG 和 Demo 隔离继续保留。

- 最终 `npm run check`：PASS，包含全项目 typecheck、unit/API tests 和 build；196 passed / 16 skipped。
- 最终 `npx tsx scripts/v1.1-happy-path.ts`：PASS。验证长 Markdown 复盘 → 直接生成 → 审核 → 实际剪贴板与预览一致；1920 / 1280 / 768 / 375px 无横向溢出，正文 16px，拒绝选择框至少 151px。桌面与手机最终截图人工复查通过。

## 2026-10-09：继续断点并完成使用验收

### ISSUE
